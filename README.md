# IPhO 2026 Lean formalization runs

This repository publishes reproducible snapshots of the IPhO 2026 Lean
formalization runs.

## Branches

- `kimi-k3`: Moonshot Kimi K3 run snapshot (source commit `adfba24`).
- `codex`: Codex 100-iteration run snapshot (source commit `caac6c8`).
- `codex-v2`: follow-up Codex run snapshot (source commit `afadf2d`).

Each run branch contains its Lean sources, blueprints, reports, references,
scripts, and durable Archon artifacts. Machine-local runtime streams, caches,
credentials, and local MCP/Codex configuration are intentionally excluded.
